# Android 测试范围（2026-10-23）

用户要求删除不符合当前开发需求的测试。CI 曾在 Android 16 模拟器中因按 Home 后未识别到桌面而失败，其余 16 项通过；该断言不能证明后台心跳功能存在回归。

本次清理内容：

- 删除依赖 Home、桌面识别、系统栏状态及多次前后台切换的 BackgroundPlaybackTest。
- 删除旧 InputEvents 界面脚本：依赖桌面、固定 `rs.ruffle` 包名、屏幕坐标和外部键盘事件，不适合作为三个分支的通用 CI 前提。
- 删除浮动菜单重载界面测试；此前浮动菜单边界与系统键盘界面集成测试也已按用户要求删除。
- 删除 roco 登录页的桌面返回集成测试，保留本地 WebView fixture 验证 iframe 参数读取及 QQ 轮询脚本的测试。
- 删除 Android 工程模板的 `2 + 2 = 4` 示例测试。
- 清理上述已删除测试不再引用的 SWF 与生成源码。

保留输入连接的组合文本提交、删除回调及旧连接隔离测试，登录协议、参数处理、错误信息、加密存储、网络策略等功能测试。SWF 启动冒烟测试直接启动 PlayerActivity 并验证 Flash trace，去掉按 Home、桌面识别和菜单点击前提。

清理不改变应用后台播放、浮动菜单、系统输入法或登录功能。删除这些界面测试后，CI 不再自动验证相应交互；发布前可结合实际游玩与日志检查。JVM 测试和 Android 测试源码编译通过不等于已在 API 26/36 模拟器执行通过，模拟器结果以本次提交对应的 CI 为准。
